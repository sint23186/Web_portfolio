What will your style test page include?

A style test page is a scratch page where you try out fonts, colours and components before building the real site — tick what you'll test.

  • Heading styles (H1–H3)
  • Body text & paragraph spacing
  • Buttons (default + hover state)
  • Navigation link states
  • Image with alt text
  • Form input example
  • Colour swatches

Advanced techniques you'll test here

Name at least two specific techniques (Digitec 2/3) — e.g. CSS Flexbox/Grid layout, hover/transition effects, custom web fonts, responsive breakpoints, CSS variables.

Conventions you'll follow

e.g. semantic HTML5 elements, consistent class naming, indentation, code comments, W3C validation.
